# QuickHerbalist

QuickHerbalist is a quick 2D items collecting game built using Pygame.

## How to Run the Game

This project uses `uv` for dependency and package management.

To run the game:
```bash
uv run quick-herbalist
```

Alternatively, you can run it as a module:
```bash
uv run python -m quick_herbalist
```
