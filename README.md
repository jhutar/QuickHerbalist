# QuickHerbalist

QuickHerbalist is a quick 2D items-collecting game built using Kivy.

## How to Run the Game

This project uses `uv` for dependency and package management.

To run the game:
```bash
uv run quick-herbalist
```

## Development

### How to run tests
```bash
make test
```

### How to run linters and formatting checks
```bash
make check-all
```
